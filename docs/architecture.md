# Architecture

How the system is put together — the Django backend, the progressive-
enhancement TypeScript frontend, and the services around them — and the
design rationale behind the handful of deliberate, non-obvious patterns
(`HssiModel`, controlled vocabularies, the shared frontend/backend form
schema, and the publish/verification model) that a newcomer would
otherwise have to reverse-engineer from the code.
