# models/software.py

The primary software entry model and the models directly tied to it:
versions, submission/curation info, the public-visibility flag, and the
edit-link queue. Touch this when adding a software metadata field or
changing how submissions are tracked or published.

**Source:** [django/website/models/software.py](../../../django/website/models/software.py)

### `VerifiedSoftware`

Flags a `Software` as published: a row with the same UUID makes it visible on the site. **Extends:** `HssiSet`

| Member | Kind | Description |
|---|---|---|
| `access` | class attribute | `PUBLIC`. |
| `target_model` | class attribute | `Software`. |
| `slug` | field | Unique URL slug for the software's detail page. |
| `create_verified(software)` | class method | Publishes a software with a new unique slug; returns `None` if it's already published. |
| `get_unique_slug(name)` | class method | Builds a slug from a name, appending `-2`, `-3`, … until it's unique. |

### `SoftwareEditQueue`

An edit link for a software entry: the row's UUID is the secret in the emailed link, so submitters can edit without an account. **Extends:** `HssiModel`

| Member | Kind | Description |
|---|---|---|
| `access` | class attribute | `PUBLIC`. |
| `default_expire_delta` | class attribute | Default link lifetime, 5 hours. |
| `created` | field | When the link was created. |
| `expiration` | field | When the link expires. |
| `target_software` | field | The `Software` the link edits. |
| `is_expired()` | method | Whether the link has expired; also true if it has no expiration. |
| `get_latest_expiry(target)` | class method | The link for a software that expires last, or `None`. |
| `create(target, expiration)` | class method | Creates and saves a link for a software, expiring after `default_expire_delta` unless given. |
